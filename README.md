# Repost News Bot

Telegram-бот: берёт текст новости, переписывает своими словами, переводит
на узбекский язык (кириллица), подбирает подходящее фото со стока (Pexels)
и публикует в ваш канал — только после вашего подтверждения.

## Как это работает

1. В личке боту или в группе, куда он добавлен, пришлите команду `/rewrite`
   ответом на пост (форвард из другого канала или обычное сообщение с
   текстом), либо сразу с текстом: `/rewrite <текст новости>`.
2. Бот пришлёт превью: фото + переписанный и переведённый текст с кнопками
   `✅ Опубликовать`, `🔄 Другое фото`, `❌ Отклонить`.
3. После нажатия «Опубликовать» пост уходит в канал, указанный в
   `TARGET_CHANNEL_ID`.

Право нажимать кнопки и запускать `/rewrite` есть только у пользователей
из `ADMIN_IDS` — это работает одинаково и в личных сообщениях, и в группах.

## Установка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите
   `BOT_TOKEN`.
2. Добавьте бота администратором в канал, куда он будет публиковать посты
   (с правом отправки сообщений). Узнайте `TARGET_CHANNEL_ID`:
   - для публичного канала — просто `@username_канала`;
   - для приватного — числовой id вида `-1001234567890` (можно получить,
     например, через @userinfobot или переслав пост из канала боту
     `@getidsbot`).
3. Узнайте свой Telegram user id (например, через @userinfobot) и впишите
   его в `ADMIN_IDS`.
4. Получите ключ Anthropic API на https://console.anthropic.com/.
5. Получите бесплатный ключ Pexels API на https://www.pexels.com/api/.
6. Скопируйте `.env.example` в `.env` и заполните все значения.
7. Установите зависимости и запустите бота:

```bash
pip install -r requirements.txt
python -m bot.main
```

8. Если хотите использовать бота в группе — добавьте его туда обычным
   способом (Add to Group). Команда `/rewrite` работает в группе так же,
   как в личке.

## Ограничения текущей версии

- Источники новостей добавляются вручную (форвард/копипаст в чат с
  ботом), автоматического мониторинга чужих каналов нет — обычный бот
  через Bot API не может читать посты каналов, где он не администратор.
  Если нужен полностью автоматический сбор с конкретных публичных
  каналов — это отдельная фича на базе Telegram user-сессии (Telethon/
  Pyrogram), которую можно добавить отдельно.
- Фото ищутся по ключевым словам среди бесплатных стоковых фото Pexels
  (без нарушения авторских прав), а не произвольным поиском по интернету.
